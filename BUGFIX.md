# BUGFIX.md — Найденные и исправленные ошибки

Документ содержит баги, обнаруженные при тестировании приложения **Task Manager**.

---

## Версия до 0.1.0 (исходный код)

### Критические / важные

| # | Описание бага | Где проявлялся | Статус |
|---|---------------|----------------|--------|
| 1 | **Опечатка в названии модуля** — файл назывался `storege.py` вместо `storage.py` | Импорты в `main.py` | ✅ Исправлено |
| 2 | **Лишние символы `\n` в данных задач** — при добавлении и редактировании в конец строки добавлялся перевод строки | `core.py` → `add_task`, `edit_task` | ✅ Исправлено |
| 3 | **Дублирование сообщений об ошибке** — при неверном номере задачи сообщение выводилось дважды (из `check_confirm` и из `delete_tasks`) | `core.py` → `delete_tasks` | ✅ Исправлено |
| 4 | **Глобальная переменная `collection`** — список задач объявлялся на уровне модуля и потом расширялся через `extend` | `main.py` | ✅ Исправлено |
| 5 | **Файл `os.py` в проекте** — перекрывал стандартный модуль Python `os`, что могло вызывать неожиданные ошибки | Корневая папка проекта | ✅ Удалён |
| 6 | **Лишний файл `processes.py`** — не использовался в приложении | Корневая папка проекта | ✅ Удалён |

### Средние

| # | Описание бага | Где проявлялся | Статус |
|---|---------------|----------------|--------|
| 7 | **Непоследовательная обработка строк** — `load_tasks` возвращал строки с `\n` (`readlines`), а отображение делало `.strip()` | `storege.py` / `view.py` | ✅ Исправлено |
| 8 | **Нумерация в `show_collection`** — использовался `enumerate` без `start=1`, потом вручную `number + 1` | `view.py` | ✅ Исправлено |
| 9 | **Отсутствие `.strip()` при вводе выбора меню** — лишние пробелы могли ломать выбор пункта | `main.py` | ✅ Исправлено |

### Мелкие / улучшения

| # | Описание | Статус |
|---|----------|--------|
| 10 | В `edit_task` и `delete_tasks` при ошибке валидации всё равно выводилось лишнее сообщение | ✅ Исправлено |
| 11 | Нет явного описания версий и изменений в docstring `main.py` | ✅ Исправлено (см. docstring) |

## Как тестировалось

- Запуск приложения и проверка всех пунктов меню
- Добавление задач с пустым названием / содержимым
- Редактирование и удаление по несуществующему номеру
- Проверка сохранения и загрузки из файла `saves.txt`
- Проверка импортов всех модулей
