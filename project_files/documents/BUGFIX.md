# BUGFIX — Task Manager

## Исправленные проблемы (по сравнению с предыдущей версией)

### Критические ошибки

1. **Сломанные импорты**  
   - Было: `from storege import ...`, `from python.TM.src.ui.interface import ...`  
   - Исправлено: корректные относительные импорты и структура пакетов.

2. **Незавершённый и синтаксически неверный `storage.py`**  
   - Было: обрыв строки `if not`, смешение load/save, чтение как текст.  
   - Исправлено: полноценные функции `load_tasks` / `save_tasks` с JSON.

3. **Дублирование класса `AppButton`**  
   - Класс объявлялся и в `Button.py`, и в `Frame.py`.  
   - Исправлено: единый файл `AppButton.py`.

4. **Некорректное хранение задач**  
   - Задачи хранились как строки `"name | content\n"`.  
   - Исправлено: список словарей → удобно сохранять в JSON и редактировать.

5. **`view.py` содержал вызов `main()` и `root.mainloop()`**  
   - Файл не должен запускать приложение.  
   - Исправлено: `view.py` содержит только функции отображения.

6. **`Listbox.delete_list` был вложен внутрь `add_to_list`**  
   - Синтаксическая ошибка.  
   - Исправлено: метод `clear()` в `AppListbox`.

7. **Отсутствие обработки ошибок при работе с файлом**  
   - Исправлено: `try/except` в `storage.py` + `ensure_saves_file`.

8. **Смешение консольной и GUI-логики**  
   - Старый `app.py` и `core.py` использовали `input()`.  
   - Исправлено: вся логика UI перенесена в `Interface`, core работает только с данными.

### Улучшения надёжности

- Добавлена проверка пустых названий/содержимого.
- Добавлено подтверждение перед удалением.
- Файл `saves.json` создаётся автоматически, если отсутствует.
- Корректная работа с путями (относительные + поддержка PyInstaller).
