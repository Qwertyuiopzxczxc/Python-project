## Версия 0.2.0 (Урок 13–14 — Слоистая архитектура)

### Реализованные улучшения

- [x] Переход на слоистую архитектуру:
  - **Storage** (`storage.py`) — работа с JSON
  - **Core** (`core.py`) — бизнес-логика (add / edit / delete)
  - **View** (`view.py`) — методы отображения
  - **Interface** (`ui/interface.py`) — сборка GUI
  - **UI-компоненты** — переиспользуемые виджеты

- [x] Кастомные классы виджетов:

- [x] Сохранение задач переведено с `.txt` на **JSON**
- [x] Задачи хранятся в структурированном виде (`{"name": ..., "content": ...}`)
- [x] Полноценный GUI на Tkinter с несколькими экранами (меню / список / добавление)
- [x] Отображение задач через собственный класс `AppListbox`
- [x] Редактирование и удаление задач прямо из списка
- [x] Валидация пустых полей
- [x] Подтверждение удаления
- [x] Автосохранение при изменениях и при выходе
